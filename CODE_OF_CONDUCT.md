# Code of conduct

Be respectful and honest with everyone who works on or uses this project. Say what you
think about the work and not about the person. Accept review of your own work in the
same spirit as you review the work of others. Credit the people whose work you build on,
and never harass, demean or exclude anyone. Report a breach to the coordinator, Tobias,
in person or through the team's own channels described in [docs/team.md]. If the
complaint involves the coordinator, the course coach decides instead. The coordinator
enforces this code and decides what follows from a breach.
